## Featured projects

**[Neuro-symbolic GORGIAS extraction](https://github.com/Mr-Noredine/neurosymbolic-gorgias-extraction)** · personal project
Turns French argumentative text into an LPP/GORGIAS logic program. A local LLM (Ollama) only answers closed questions; spaCy and deterministic rules decide the rest. Hand-annotated benchmark with negative examples, 97.9% rule precision, 171 tests.
`Python` `Ollama` `spaCy` `neuro-symbolic AI`
